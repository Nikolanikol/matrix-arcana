# Design System — Matrix Arcana

## Design intent

Premium mystical editorial: atmospheric, refined, modern, and legible. Avoid a cluttered occult-shop aesthetic, excessive glow, noisy gradients, and decorative elements that compete with content.

## Initial visual direction

These are provisional design principles, not final locked brand tokens. Propose actual color values and font pairings for approval before treating them as final.

- Deep, dark foundations balanced with warm light surfaces where appropriate.
- Restrained metallic or jewel-tone accents.
- High-contrast, readable text.
- Large editorial headings paired with highly legible body text.
- Fine borders, subtle texture, and sparse celestial or geometric motifs.
- Motion should be slow and purposeful, with reduced-motion support.

## Layout

- Design mobile-first and scale to tablet and desktop.
- Use a consistent spacing scale and a clear typographic hierarchy.
- Keep primary actions visually obvious.
- Avoid overly narrow text columns on desktop and cramped layouts on mobile.
- Establish reusable page containers, grids, and section spacing.

## Components to plan

- Application shell and navigation
- Buttons and links
- Form controls
- Cards and content panels
- Tabs or segmented navigation where useful
- Dialogs and drawers if required by the user flow
- Loading, empty, error, and success states
- Language selector

## Accessibility

- Semantic HTML and visible keyboard focus.
- Sufficient text contrast.
- Inputs with labels and understandable validation.
- Do not communicate meaning through color alone.
- Respect `prefers-reduced-motion`.

## Before implementation

Present a compact visual proposal with palette, font candidates, spacing/type scale, and examples of key components. Keep tokens centralized. Do not introduce a large component library without approval.
